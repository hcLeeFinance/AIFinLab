================================================================================
beta/ 目錄說明（shinylive 0.5.0）
================================================================================
beta/ 是 shinylive::export() 自動生成的產物，不應手動修改。

關鍵檔案：
  beta/app.json                      ← source_beta/ 的 R 程式碼打包
  beta/shinylive/webr/R.js           ← WebR R 執行引擎啟動器（舊版為 R.bin.js）
  beta/shinylive/webr/R.wasm         ← R 編譯成 WebAssembly（舊版為 R.bin.wasm）
  beta/shinylive/webr/library.data.gz ← R 套件（zoo、quantmod 等）整合包

注意：R.js.bak 是 shinylive 自動產生的備份（比 R.js 多 19 bytes），正常現象。

================================================================================
開發流程
================================================================================
1. 編輯 source_beta/app.R
2. 執行：Rscript build_site.R
3. git add beta/ && git commit && git push
